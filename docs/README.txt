Golden Gate Group Investments website

1. Keep a backup of your current website files.
2. Extract this ZIP.
3. Copy index.html, images/, and styles/ into your website's publishing directory, replacing matching files.
4. If using GitHub Pages, commit and push those files to the configured publishing branch/directory.
5. Reload your website. If the old styling remains, hard-refresh the page.

The package uses plain HTML and CSS, with no dependencies or build step.
Open index.html directly to preview locally.

Included assets:
images/logo-icon.png — approved borderless square bridge logo (also favicon)
images/golden-gate-banner.jpg — approved panoramic profile banner
styles/styles.css — responsive page styling
index.html — updated company content

Company property holdings are described as Texas. Bitcoin payments, reserves, and acquisitions are described as goals.

Layout: full-screen bridge background, centered translucent content box at 50vw on desktop, 72vw on tablets, and viewport width minus 32px on phones. To adjust desktop width, change --panel-width:50vw in styles/styles.css.
